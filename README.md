## Описание проекта

Eco-Activist Backend предоставляет RESTful API для клиентских веб- и мобильных приложений. Сервис обеспечивает взаимодействие между организаторами экологических мероприятий и участниками, автоматизирует регистрацию, учет посещаемости и начисление баллов активности.

---

## Технологический стек

| Категория | Технологии |
| :--- | :--- |
| **Платформа** | .NET 8 / .NET 9 (C#) |
| **Архитектура** | Clean Architecture / CQRS |
| **База данных** | PostgreSQL |
| **ORM** | Entity Framework Core |
| **Аутентификация** | JWT (JSON Web Tokens) |
| **Контейнеризация** | Docker, Docker Compose |
| **Документация** | Swagger / OpenAPI |

---

## Ключевой функционал

- **Управление пользователями:** регистрация, авторизация (JWT), управление ролями (волонтер, организатор, администратор).
- **Эко-мероприятия:** создание, редактирование и публикация событий (субботники, лекции, раздельный сбор отходов).
- **Учет участия:** запись на события, генерация и валидация QR-кодов для подтверждения присутствия на локации.
- **Геймификация и рейтинги:** учет выполненных активностей, начисление баллов и формирование таблицы лидеров.

---

## Требования к окружению

Перед началом работы убедитесь, что в системе установлены:

- **.NET SDK** (версия 8.0 или выше)
- **Git**
- **Docker** и **Docker Compose** (рекомендуется для быстрого подъема БД)
- *Опционально:* СУБД **PostgreSQL 15+** (если запуск базы планируется без Docker)
